# group_04_project

## Usage

### Clone the Repository
```bash
git clone https://gitlab.engr.illinois.edu/ie421_high_frequency_trading_spring_2024/ie421_hft_spring_2024_group_04/group_04_project.git
```

### Implement the Strategy
Implement the strategy (abstract class) in ./src/sample_strategy.h

### Run Backtest
```bash
sh run_backtest.sh <Initial Spot Balance> <Initial Futures Balance> <Configuration Path> <Market Data Path>
sh run_latency_analysis.sh <Initial Spot Balance> <Initial Futures Balance> <Configuration Path> <Market Data Path>
```
#### Example:
```bash
sh run_backtest.sh 100 100 ./configuration ./sample_data/sample_market_data.csv
```
